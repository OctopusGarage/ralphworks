# Shared harness report outline

1. Fresh assessment: scope, available evidence, unavailable checks, urgent risks.
2. Strategy and shared budget: selected specialties/order; skipped specialties and reasons.
3. Each coherent change: baseline, cause or gap, repair, relevant method, exact checks and results.
4. Remaining budget, unresolved failures, unmeasured claims, and deferred work.

Write only HARNESS_REPORT.md under this profile. No numeric health score or implicit coverage threshold is supplied.
