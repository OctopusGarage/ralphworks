# Code review method

Review {{scope}}. Read repository instructions, the change's requirements, and the relevant implementation and tests.
Identify concrete correctness, security, compatibility, and maintainability issues introduced by the change.
For each finding, provide severity, a file and line reference, the triggering condition, the consequence, and a focused remedy.
Check uncertain claims against the code or a targeted command. Separate confirmed findings from unverified questions.
Write REVIEW.md with findings ordered by severity and a short account of verification and remaining limitations.
If no actionable findings remain, say so explicitly. Keep source modifications outside the review task unless requested.
