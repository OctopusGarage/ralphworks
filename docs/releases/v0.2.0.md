RalphWorks can run scheduled architecture surveys with a selected Matt Pocock skill snapshot and record the exact source commit used.

## Highlights

- Generated architecture workflows can fetch `improve-codebase-architecture` from a pinned commit or the latest commit on a selected branch, publish a visual report artifact, and create a concise proposal Issue.
- Custom Pi agent directories are passed to session resource discovery, so their installed skills are available during a run.
- The Biome and Knip development dependencies were updated; the Biome configuration schema now matches the installed CLI version.

## Upgrade notes

Install v0.2.0 before running `ralphworks init` in a new target repository. Existing installations keep their workflow files; compare the generated `ralphworks-architecture.yml` with the target's copy and apply the reviewed changes to enable skill snapshots. Set `RALPHWORKS_ARCHITECTURE_SKILL_REF` to a reviewed commit SHA or branch only when that behavior is wanted.

## Install

```bash
npm install -g @earendil-works/pi-coding-agent \
  https://github.com/OctopusGarage/ralphworks/releases/download/v0.2.0/ralphworks-0.2.0.tgz
```
