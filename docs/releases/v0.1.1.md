RalphWorks runs bounded coding loops and turns issue and PR tasks into checked, reviewable GitHub work.

## Highlights

- Generate workflows for issue implementation, PRD splitting and delivery, dependency queues, PR review and feedback, branch updates, and architecture proposals.
- Run Pi in fresh iterations with saved progress, independent checks, and limits on iterations, time, and reported cost.
- Resume a failed PRD split delivery without duplicating matching sub-issues, and inspect queued issues across API pages.
- Validate maintained and generated workflows with actionlint as part of local and CI verification.

## Install

```bash
npm install -g @earendil-works/pi-coding-agent \
  https://github.com/OctopusGarage/ralphworks/releases/download/v0.1.1/ralphworks-0.1.1.tgz
```
